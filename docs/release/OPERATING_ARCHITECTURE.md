# معمارية التشغيل والتسليم

## المبدأ
المنصة ليست مجموعة صفحات مستقلة. **سجل المبادرة هو العقدة المركزية**، وكل بوابة تؤدي وظيفة محددة في دورة العمل.

`السجل → التشخيص → الجاهزية → القرار → الاحتياج → التنفيذ والمتابعة → الإنجاز → الاستلام → الأرشيف → التقارير`

## مصادر الحقيقة
1. قاعدة المبادرات: الهوية، الدراسة، الأعمال والكميات المعتمدة، الإنجاز والمساهمات والحالة.
2. سجل الأسمنت: معاملات الوارد والمنصرف وأوامر الصرف والدفعات والأسعار والأرصدة.
3. سجل الديزل: معاملات الوارد والمنصرف وأوامر الصرف والدفعات والأسعار والأرصدة.
4. الأدلة الميدانية والوثائق: أحداث جديدة موثقة وليست بديلًا عن المصدر المرجعي.
5. القوالب الأصلية: مصدر شكل النموذج وتنسيقه، ولا يعاد رسمها كبديل عند التصدير.

## قاعدة عدم الاختلاق
القيمة غير الموجودة في المصدر تبقى فارغة أو `غير موثق`. لا تُولد أرقام هواتف أو كميات أو تواريخ أو توقيعات أو نتائج ميدانية من الواجهة.

## قاعدة المعاملات
كل حركة مادة تبقى كسجل مستقل، بينما تعرض المنصة ملخصًا للمبادرة مع إمكانية فتح الحركات الأصلية.

## GitHub / AI Studio
- `src/` للكود التطبيقي.
- `src/data/` للبيانات المرجعية المولدة والمحوّلة.
- `src/forms/` لتعريفات النماذج ومحلل البيانات.
- `src/navigation/` لنموذج التنقل التشغيلي.
- `public/templates/` للقوالب الأصلية.
- `public/data/` للمصادر المكانية المعتمدة.
- `scripts/` للتحقق وإعادة التوليد، وليس لتخزين بيانات تشغيلية سرية.
- `docs/release/` لوثائق التسليم والقرارات المعمارية.
