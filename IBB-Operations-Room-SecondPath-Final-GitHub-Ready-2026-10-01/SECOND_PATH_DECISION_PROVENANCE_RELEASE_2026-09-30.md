# غرفة عمليات إب — طبقة مصدر القرار

## ما تم تنفيذه
- إضافة بوابة **مصدر القرار** داخل المسار التنفيذي الثاني.
- عرض سلسلة قابلة للتدقيق: **المصادر → الأدلة → التوصية التشغيلية → القرار الرسمي**.
- ربط هوية المبادرة بالسجل المرجعي، والحالة بالفرز، والإنجاز بالتقييم، والمطابقة/الفروقات بالتقييم والفرز، والمواد بسجلات المواد، والجاهزية/الملكية بسجل المبادرة.
- التوصية التشغيلية تعرض كـ **توصية** ولا تُعامل كقرار معتمد.
- القرار الرسمي يعرض منفصلًا ويُفتح من مركز القرار لتسجيل صاحب الصلاحية والإجراء المعتمد.
- إضافة قاعدة تتبع واضحة داخل الواجهة: كل معلومة لها مصدر، والتوصية ليست قرارًا.

## مصادر الحقيقة المعتمدة
- السجل المرجعي للمبادرات (725 مبادرة)
- الدراسات
- مصفوفة مستوى الانجاز والتقييم
- مصفوفة الفرز
- سجلات الشطب/المواد
- سجلات المتابعة والوثائق داخل المنصة

## ملاحظات التحقق
- `npm run validate:pathway` = PASS
- لم يتم الادعاء بنجاح TypeScript الكامل لأن `node_modules/.bin/tsc` غير موجود في بيئة الإصدار الحالية.
- تم الحفاظ على بنية React/Firebase/RBAC الحالية، والإضافة داخل بوابة المسار بدل إنشاء منصة موازية.
