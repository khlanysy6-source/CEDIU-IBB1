# إصدار القيادة v3 — المسار التنفيذي الثاني

## ما تم تنفيذه
- جعل القرار/الإجراء هو العنصر الرئيسي في الواجهة القيادية.
- إضافة قائمة «ماذا يحتاج القرار الآن؟» مرتبطة بسجل القرارات والمبادرات.
- إضافة بحث موحد برقم المبادرة أو اسمها أو المديرية، مع فتح ملف المبادرة مباشرة عند اختيار النتيجة.
- جعل «مصدر القرار» هامشاً صغيراً داخل بطاقة القرار، مع فتح ملف نفس المبادرة مباشرة.
- الإبقاء على لوحة مصدر القرار التفصيلية كطبقة تحقق اختيارية، وليست واجهة رئيسية مزدحمة.
- فصل التوصية التشغيلية عن القرار الرسمي المعتمد.
- الحفاظ على بوابة المسار التنفيذي الثاني والتنقل الجانبي وإعادة استخدام المكونات القائمة.

## قاعدة العرض القيادي
القرار أولاً → السبب المختصر → مصدر صغير قابل للفتح → التفاصيل عند الحاجة.
