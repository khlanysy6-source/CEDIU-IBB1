# غرفة عمليات IBB — المسار التنفيذي الثاني

هذه هي الحزمة النهائية المنظمة كمشروع مستقل قابل للاستيراد إلى GitHub ثم فتحه/استيراده في Google AI Studio.

## ما تم تثبيته
- سجل مرجعي لـ725 مبادرة، دون بيانات اصطناعية.
- `src/` و`public/` كاملان في جذر المشروع، و`package.json` في الجذر.
- القالب المرجعي الحالي `second-path-master-template.xlsx` مأخوذ من ملف 26-9-2026م (29 ورقة).
- بوابة النماذج تعتمد على قالب Excel نفسه؛ لا يعاد رسم النماذج بصرياً.
- التصدير يوفر Excel للقالب وPDF للطباعة عند توفر Python وLibreOffice في بيئة التشغيل.
- EXC محفوظ كمفتاح لبنود الأعمال في مصفوفة مستوى الإنجاز والتقييم.
- المصادر القديمة/المكررة لا تُعامل كمصدر حقيقة تشغيلي.

## الاستيراد إلى GitHub
1. أنشئ مستودعاً جديداً.
2. ارفع **محتويات هذا المجلد كما هي** إلى جذر المستودع؛ يجب أن يكون `package.json` في الجذر.
3. لا تضع المشروع داخل مجلد فرعي داخل المستودع.
4. احتفظ بـ`src/` و`public/` و`scripts/` وملفات Firebase/الخرائط دون نقل.

## الاستيراد إلى Google AI Studio
افتح مشروعك الحالي في Google AI Studio، ثم استورد المستودع/الملفات من GitHub، ووجّه الوكيل إلى قراءة `GITHUB_IMPORT.md` ثم `AGENTS.md` قبل أي تعديل.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## الفحوص
```bash
npm run validate:data
npm run validate:forms
npm run validate:pathway
npm run lint
```
ملاحظة: اكتمال `lint`/`build` يتطلب تثبيت الاعتمادات.
